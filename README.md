CyberGuard 🔐
A Cybersecurity Awareness Chatbot built with C# to educate users about online safety, password security, phishing attacks, privacy protection, and other cybersecurity topics.
CyberGuard started as a console-based chatbot and is being expanded into a Windows Forms GUI application with advanced features such as task management, reminders, quizzes, sentiment-aware responses, and activity logging.
🚀 Features
✅ Part 1 & 2 Features
Interactive cybersecurity chatbot
Keyword recognition system
Password strength checker
Randomized cybersecurity tips
Conversation flow support
Sentiment-aware responses
Personalized responses using user memory
Dynamic chatbot responses
Typing simulation effect
Audio greeting support
✅ Part 3 Features (GUI)
Task Assistant with reminders
Cybersecurity Quiz Mini-Game
NLP (Natural Language Processing) simulation
Activity logging system
Windows Forms graphical interface
Task management (add, complete, delete tasks)
Reminder scheduling
Score tracking for quizzes
