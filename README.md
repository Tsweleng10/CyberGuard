# CyberGuard 🔐

A **Cybersecurity Awareness Chatbot** built with C# to educate users about online safety, password security, phishing attacks, privacy protection, and other cybersecurity topics.

CyberGuard started as a console-based chatbot and has been expanded into a **Windows Forms GUI application** with advanced features including task management, reminders, quizzes, sentiment-aware responses, and activity logging.

---

## 🚀 Features

### ✅ Part 1 & 2 — Console Chatbot

- Interactive cybersecurity chatbot
- Keyword recognition system
- Password strength checker
- Randomized cybersecurity tips
- Conversation flow support
- Sentiment-aware responses
- Personalized responses using user memory
- Dynamic chatbot responses
- Typing simulation effect
- Audio greeting support

### ✅ Part 3 — GUI Application

- Windows Forms graphical interface
- Task Assistant with reminders
- Cybersecurity Quiz Mini-Game
- NLP (Natural Language Processing) simulation
- Activity logging system
- Task management (add, complete, delete tasks)
- Reminder scheduling
- Score tracking for quizzes

## 🎮 Example Interactions

### 💬 Chatbot

```
User: I am worried about phishing scams

Bot:  It's completely understandable to feel that way.
      Scammers can be very convincing.
      Here are some tips to help you stay safe online...
```

### ✅ Task Assistant

```
User: Add task - Enable two-factor authentication

Bot:  Task added successfully.
      Would you like to set a reminder?
```

### 🧠 Quiz

```
Question:
What should you do if you receive an email asking for your password?

  A) Reply with your password
  B) Delete the email
  C) Report it as phishing
  D) Ignore it

✅ Correct Answer: C
```

## ⚡ Installation

1. **Clone the repository:**

   ```bash
   git clone https://github.com/Tsweleng10/CyberGuard.git
   ```

2. **Open** the solution file (`.sln`) in **Visual Studio**

3. **Build** the solution (`Ctrl + Shift + B`)

4. **Run** the project (`F5`)
